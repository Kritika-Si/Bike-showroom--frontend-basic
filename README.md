## 📌 Overview

**VELOCITY** is a premium frontend bike showroom website that showcases high-performance motorcycles through a modern, responsive, and interactive user interface. The project allows users to browse bikes, search models, filter categories, compare specifications, and book a test ride.

This project demonstrates frontend development skills using **HTML, CSS, and JavaScript** without any frameworks.

---

## ✨ Features

* 🏍️ Premium fullscreen hero section
* 🎞️ Auto-scrolling featured bike carousel
* 🔍 Live search functionality
* 🗂️ Category-based filtering
* 📊 Bike specification comparison table
* 📋 Interactive bike details modal
* 📝 Test ride booking form
* 📱 Fully responsive design
* 🌙 Modern dark premium UI

## 💻 How to Run Locally

1. Clone the repository

```bash
git clone https://github.com/Kritika-Si/Bike-showroom--frontend-basic.git
```

2. Open the project folder

```bash
cd Bike-showroom--frontend-basic
```

3. Open `index.html` using **Live Server** in VS Code.
